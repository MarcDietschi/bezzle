Microsoft Visual C++ Redistributable files

Bezzle for Windows carries, beside Bezzle.exe, files of the Microsoft Visual C++ runtime
(vcruntime140.dll and, where needed, vcruntime140_1.dll, msvcp140.dll and their companions), which
the Swift runtime and Bezzle are built against.
